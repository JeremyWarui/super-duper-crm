common jobs, using the names of the pages and buttons as they appear on screen.

## Things every guide assumes

- Everyone signs in with **email and password**.
- **Forgot your password?** on the sign-in page emails you a link. The link works for an
  hour. A new login's first link (an invite) works for 72 hours.
- Only the superuser (whoever runs the installation) can send a reset link to someone else.
  Nobody can see another person's password, and on the website nobody can set it. The IT
  person can set one from the server as a last resort.
- **Sign out** clears anything a phone has kept but not yet sent. Send your entries first.
- After you sign in on a phone, the workspace offers **Enable call alerts**, so the phone
  rings when the team starts a call. On an iPhone it works only from the Home Screen app: tap
  Share, then **Add to Home Screen**, and open the app from there (iOS 16.4 or later).
